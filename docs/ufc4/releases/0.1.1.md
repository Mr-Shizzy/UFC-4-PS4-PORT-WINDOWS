# EA SPORTS UFC 4 Windows Port - Release v0.1.1

## What's Changed
* **Fix Post-Match Victory Crash (SimThread Code 3):**
  - Resolved null pointer dereference at guest offset `0x32f81b` / `0x32affa` during post-match victory celebration and fight result gathering.
  - Added shared safe trampoline at `0x72f981` with tail-call virtual dispatch bypass.
  - Allows full matches to complete cleanly: knockout / finish, victory celebration, fighter hand-raise, and post-match statistics screen.
* **Updated Stability Patch Suite:**
  - `out/patches.bin` recompiled with 47 patches (62 active writes).
  - Precompiled `out/patches.bin` and `out/import_names.txt` now packaged directly into the release archive.
* **Hair Anti-Dithering & Alpha-to-Coverage:**
  - Included `BB_ALPHA_TO_MASK=coverage` in default `run_game.bat` configuration for smooth fighter hair rendering without checkerboard artifacts.

## Packaging
* Release bundle: `UFC4Native-ufc4-v0.1.1-windows-x86_64.zip`
