Native EA SPORTS UFC 4 port (PS4 `CUSA14209`, update 28.00) for Windows.
**No game files are included**: you need your own dump of the game and its 28.00 update.

### Download
`UFC4Native-ufc4-v0.1.1-windows-x86_64.zip` — extract (not inside a OneDrive folder), run `UFC4.exe`, pick the `CUSA14209` folder (merged update), press **START FIGHT**.

### Changes in 0.1.1
- **Match victory & post-fight crash fix (SimThread code 3):** in offline fights, winning by knockout, submission, or decision caused the game to crash immediately during the victory celebration at guest offset `0x32f81b`. The engine attempted to query uninitialized telemetry via `call [rax + 0x50]`, dereferencing a NULL pointer (`mov rcx, [rax]`).
  - Added an in-memory null-safety trampoline at `0x72f981`.
  - Patched both corner result dispatchers (`0x72f81b` for winner corner, `0x72affa` for secondary corner).
  - Matches now transition smoothly into celebration cutscenes, fighter hand-raise, and post-fight statistics screens.
- **Hair anti-dithering:** enabled Vulkan Alpha-to-Coverage (`BB_ALPHA_TO_MASK=coverage`) by default in `run_game.bat` for smooth fighter hair rendering without checkerboard artifacts.
- **Precompiled runtime assets:** `out/patches.bin` (47 stability patches, 62 active writes) and `out/import_names.txt` are now bundled directly inside the release archive for seamless setup.

### Performance
- RTX 4060 Laptop GPU: menus 240 FPS (the game's cap), fights steady ~117–120 FPS at 1080p Vulkan 1.4.

### Known issues
- Online multiplayer is unavailable (offline local play only).
- Untested on Intel Arc / older AMD GPUs (LDS memory barrier toggles available in `run_game.bat`).

Problems: attach the newest log from `logs\latest.log`.
